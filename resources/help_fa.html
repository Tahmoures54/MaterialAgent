راهنمای کاربری iMat Warehouse

سیستم کنترل مواد برای پروژه‌های EPC — نسخه ۲.۲

خوش آمدید

iMat با PyQt6 ساخته شده و به‌صورت پیش‌فرض روی SQLite کار می‌کند. از نسخه ۲.۲ امکان اتصال به SQL Server برای کار تحت شبکه فراهم است.

انتخاب دیتابیس: SQLite یا SQL Server

حالتمناسب برای
SQLite (پیش‌فرض)تک‌کاربره، آفلاین
SQL Serverچندکاربره تحت شبکه

فعال‌سازی SQL Server

  1. نصب ODBC Driver 17/18 مایکروسافت
  2. pip install pyodbc
  3. در app_config.json: database.engine = "sqlserver" و پر کردن بخش sqlserver

توجه: بک‌آپ فایل‌بیس فقط در حالت SQLite است.
