    🌟 Welcome to iMat

    iMat is an advanced desktop application designed specifically for material and inventory management in complex EPC (Engineering, Procurement, and Construction) projects. Built with SQLite and PyQt6, it combines heavy-duty inventory control with modern AI forecasting capabilities.

    💡 Five Core User Roles: Admin, Operator, Technical Office, QC Inspector, and Viewer. Each role has a customized interface with specific permissions.
    🔒 Offline-First Architecture: Operates entirely without an internet connection, ensuring data security on remote sites. Internet only required for license verification and WhatsApp sharing.

    Key Features

    📦 Material Control

    Comprehensive item coding, multi-warehouse mapping, and document management (MRR, MIV, MSR, OS&D).

    📐 Technical Office

    Material requests, requisitions, live stock dashboard, and end-to-end traceability.

    ✅ Quality Control

    QC release from quarantine, preservation scheduling, certificate linking, and batch tracking.

    📊 Reports & Export

    Unified report manager with export to Excel, PDF, HTML. Customizable filters and views.

    🤖 AI-Powered Tools

    Demand prediction, ABC analysis, reorder point optimization, and barcode reader integration.

    👥 Teamwork & Security

    Role-based access, user management, audit-ready viewer role, and license activation.

    🚀 Quick Start in 6 Steps

    1. Upon initial startup, register your master Admin account. You can add more users via Teamwork → Manage Users & Roles.

    2. Navigate to Material Control → Material Catalog. Define item codes, descriptions, dimensions, and units.

    3. Go to Material Control → Warehouse & Locations. Build your hierarchy: Warehouse → Rack → Bin.

    4. Click New Document to generate MRR (Receiving), MIV (Issue), MSR (Requisition), or OS&D reports.

    5. Use Quality Control → QC Release to inspect and move materials from quarantine to accepted stock.

    6. Utilize AI Demand Prediction, ABC Analysis, and the Reorder Point Calculator to optimize inventory.

    🔄 Core Workflows

    📦 Material Receipt (MRR)

    1. Create MRR Document

      Navigate to Material Control → New Document → select MRR type.

    2. Enter Header Info

      Fill PO number, vendor, delivery note, and document date.

    3. Add Line Items

      Enter item codes, heat numbers, quantities, and storage locations.

    4. Save Document

      Stock is automatically added to QUARANTINE status.

    5. QC Inspection

      QC Inspector reviews and accepts/rejects materials.

    📤 Material Issue (MIV)

    1. Create MIV Document

      Select MIV type when creating a new document.

    2. Select Items

      Choose from ACCEPTED stock only. System validates availability.

    3. Specify Destination

      Enter subcontractor, ISO drawing reference, and work area.

    4. Save & Issue

      Stock is automatically deducted from inventory.

    🔄 Material Transfer (MTR)

    1. Create MTR Document

      Select MTR type for location-to-location transfers.

    2. Specify Source & Destination

      Select from and to locations.

    3. Add Items

      Enter items with heat numbers and quantities to transfer.

    4. Execute Transfer

      Stock is moved between locations automatically.

    📦 Material Coding System

    The coding system is the backbone of iMat. Every material must be defined here before it can be received or issued.

    Sample Material Codes

    CodeDescriptionUnitDiscipline
    PIP-CS-6-S40Pipe, Carbon Steel, 6", SCH 40MTRPiping
    FLG-WN-8-CL300Flange, Weld Neck, 8", Class 300NOSPiping
    CBL-PWR-3C95Power Cable, 3x95 mm², Cu/XLPEMTRElectrical
    VLV-GATE-4-CL150Gate Valve, 4", Class 150NOSMechanical

    Coding Convention

    Recommended format: {TYPE}-{MATERIAL}-{SIZE}-{RATING}

    • TYPE: PIP (Pipe), FLG (Flange), VLV (Valve), CBL (Cable), FIT (Fitting)
    • MATERIAL: CS (Carbon Steel), SS (Stainless Steel), CU (Copper)
    • SIZE: Nominal size in inches or mm
    • RATING: Schedule, Class, or specification

    🤖 Smart Inventory Tools

    🔮 AI Demand Prediction

    Analyzes historical issue rates using ML algorithms to forecast material requirements for 7, 14, or 30 days ahead.

    📊 ABC Analysis

    Automatically classifies inventory into A (high value), B (medium), and C (low) to prioritize management efforts.

    📈 Reorder Point Calculator

    Calculates optimal safety stock levels and triggers alerts when items dip below critical thresholds.

    ⌛ Expiry Date Monitor

    Color-coded alerts warn you 30, 7, and 0 days before materials expire. Crucial for chemicals and consumables.

    📷 Barcode Scanner

    Floating widget that lets you scan QR/Barcode from any screen to instantly pull up item location and history.

    🛡️ Preservation Dashboard

    Monitor preservation schedules with automatic next-due calculations based on material class.
