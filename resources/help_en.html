iMat Warehouse User Manual

Material Control System for EPC Projects — Version 2.2

Welcome

iMat is built with PyQt6 and defaults to SQLite. From version 2.2 you can also connect to SQL Server for multi-user network use.

Database: SQLite or SQL Server

ModeBest for
SQLite (default)Single-user, offline
SQL ServerMulti-user on a network

Enabling SQL Server

  1. Install Microsoft ODBC Driver 17/18
  2. pip install pyodbc
  3. In app_config.json: set database.engine = "sqlserver" and fill the sqlserver section

Note: File-based backup is SQLite-only.

AI Features

  • Demand prediction with ensemble and intermittent methods
  • EOQ, Safety Stock, ABC analysis
  • Offline Q&A assistant (English / Persian)
