1. Quick Start

  1. Log in (Admin creates users under Teamwork → Manage Users).
  2. Define items in Material Control → Material Coding.
  3. Map Warehouse → Rack → Bin under Warehouse & Locations.
  4. Receive stock with an MRR (quarantine).
  5. Release with QC Release, then issue with MIV.
Integrity: Deleting a Draft document reverses any stock it posted so inventory cannot silently inflate.

2. Core Document Flow

MRR Receive → QC Release → MIV Issue

Also: MTR (transfer), OS&D, Material Requests, Preservation, Expiry monitoring.

3. Database: SQLite or SQL Server

ModeBest for
SQLite (default)Single user, offline site laptop
SQL ServerMulti-user on a company network

Switch via UI

System → Settings (Admin). Choose engine, fill SQL Server fields if needed, Save, then restart the app.

Or via app_config.json

"database": {
  "engine": "sqlserver",
  "sqlserver": {
    "enabled": true,
    "server": "YOUR_SERVER",
    "database": "iMat",
    "username": "imat_user",
    "password": "********",
    "driver": "ODBC Driver 17 for SQL Server"
  }
}
Note: File backups apply only to SQLite. For SQL Server use server backups. Install ODBC Driver 17/18 and pip install pyodbc on each client.
